# Smyrna Volzhevska — Game Design Portfolio

Portfolio projects for Metropolia UAS Game Design (Bachelor) admission.

## Projects

### [Blue Moon — Interactive 3D Space Scene](blue-moon-3d/)

A real-time 3D scene: a blue-lit Moon floating in space, freely rotatable and
zoomable, built with Three.js. Texture and relief pipeline written in Python
on top of real NASA lunar data (LROC photography + LOLA elevation), re-graded
to match an artistic blue reference image.

**[Live demo](https://smyrnav.github.io/game-design-portfolio/blue-moon-3d/)**
